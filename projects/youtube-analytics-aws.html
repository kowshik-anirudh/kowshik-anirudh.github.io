YouTube Trending Analytics on AWS

A serverless data lake for trending YouTube videos across seven regions. Raw CSV and JSON land in S3, an event-driven Lambda cleans them into Parquet, Glue catalogs and joins them, and Athena and QuickSight serve the analysis.

01Architecture

  1. IngestRaw statistics CSVs and category JSON files are uploaded to S3, partitioned by region.
  2. CleanAn S3 event triggers a Lambda that flattens the nested JSON and writes Parquet to a cleansed zone.
  3. Catalog and transformGlue crawlers register schemas, and a Glue ETL job joins statistics to categories.
  4. AnalyzePartitioned Parquet is queried with Athena and visualized in QuickSight.

02How it works

  • Event-driven cleaning: new JSON files in the raw bucket trigger a Lambda that flattens the nested items array with pandas and writes Parquet through AWS Data Wrangler, updating the Glue Data Catalog as it goes.
  • Glue ETL: PySpark jobs convert the regional CSVs to Parquet partitioned by region, then join video statistics to category names on category_id into an analytics table.
  • Columnar storage: Parquet plus partitioning keeps Athena scans small and fast compared with querying raw CSV and JSON.
  • Access control: IAM roles scope what Lambda and Glue can read and write.
