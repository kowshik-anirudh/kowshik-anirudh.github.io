Tokyo Olympics Analytics on Azure

An end-to-end Azure pipeline over the Tokyo 2020 Olympics dataset (11,000+ athletes, 47 disciplines, 743 teams), from ingestion with Data Factory through Spark transformations in Databricks to SQL analytics in Synapse.

  • Azure Data Factory
  • ADLS Gen2
  • Databricks
  • PySpark
  • Synapse Analytics
  • SQL
Source code

01Architecture

  1. IngestData Factory copy activities pull five CSV datasets over HTTP into ADLS Gen2.
  2. StoreThe data lake holds separate raw and transformed zones.
  3. TransformDatabricks mounts the lake with a service principal and processes the data in PySpark.
  4. AnalyzeSynapse lake database tables over the transformed data, queried with SQL.

02How it works

  • Ingestion: a single Data Factory pipeline chains copy activities for athletes, coaches, teams, medals and entries by gender, landing them in the raw zone.
  • Secure lake access: Databricks mounts ADLS Gen2 with OAuth through an Azure AD service principal, with credentials read from a Databricks secret scope.
  • Transformation: PySpark reads each dataset with schema inference, checks the schemas, and writes cleaned outputs to the transformed zone.
  • Analytics: SQL in Synapse covers medal tables by country, athletes and coaches per country, and gender balance by discipline.

Started as a guided learning project. Sources are credited in the repository.
